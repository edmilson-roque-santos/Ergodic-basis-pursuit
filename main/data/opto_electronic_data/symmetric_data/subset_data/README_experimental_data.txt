Data from Joseph D Hart (joseph.hart@nrl.navy.mil)
US Naval Research Laboratory, US

The data was taken at University of Maryland, College Park using the experimental apparatus described in (Hart JD, Zhang Y, Roy R, Motter AE. Topological control of synchronization patterns: Trading symmetry for stability. Physical review letters. 2019 Feb 8;122(5):058301.). The network structure corresponds to the symmetric adjacency matrix. Parameters: beta = 4.5, phi (bias) = pi/4. coupling strength sigma = 0.171875

The original data was pos-processed to select a subset between [3.4,4.5] as described in the supplementary material of the main paper: Robust reconstruction of sparse network dynamics. 

The file experimental_data.csv corresponds to the multivariate time series with rows (time) and columns (nodes) of the network dynamics.
